# Sprig 0.7.0

Organize is now **Sprig**, with a new card-and-leaf logo that follows your theme.

- **Color by Feature** adds a front band split among a task's assigned Features, alongside its project band.
  Unassigned tasks keep only the project band. The toggle starts on and remembers your choice.
- Both bands default to 5 px. **Preferences > Card color band thickness** adjusts them from 3-10 px.
- Drag a card body, title or grip between lanes. Empty lanes accept drops on their message area.
  Clicking still opens details; the existing status controls remain available.
- Feature labels identify the colors on full cards; condensed cards remain compact.

Existing projects, ticket IDs and relationships are retained. Data stays in the existing ProjectOrganize
folder, and the organizer CLI and snapshot contract remain compatible. No database migration is required.
This finishes the requested feature round; the version history continues forward as 0.7.0.

Save or close editors before restarting. An open browser reconnects to the updated local app.
