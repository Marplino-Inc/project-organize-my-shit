# v1.0.0-work

Derived from personal Sprig 1.2.0 (daf2b10), removing work-item Features throughout while retaining
other workflows. Work-specific storage, snapshot identity and local browser controls isolate this edition.
Main and work remain active branches; this tag is a fixed release, not a frozen branch.

## Install and agent handoff

Extract sprig-work-1.0.0-work-source.zip into a local folder. On an employer-approved macOS 13+
Apple Silicon system with uv, run `sh Setup.command`, then `sh Start.command`.
Open http://127.0.0.1:8775. Stop the foreground process with Ctrl+C before updating.
Read AGENT_HANDOFF.md for GitHub Copilot in VS Code; the JSON CLI is model-independent.
Python metadata uses 1.0.0+work; the release/tag label is v1.0.0-work.
