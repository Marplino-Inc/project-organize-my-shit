# Organize 0.6.0

Features organize overlapping areas of work within a project.

- Define Features in **Edit project ? Features**, with a name and optional description.
- Select one or more Features in a work item's editor, or leave it unassigned.
- Filter the existing board by Feature. New items in a filtered view preselect that Feature.
- Full cards and details show Feature badges; condensed cards stay compact.
- Rename Features without changing membership or ticket IDs. Unassign a Feature from all items before deleting it.
- One work item remains one record and counts once, even when associated with multiple Features.

Feature membership is independent of parent relationships and does not inherit automatically.
Snapshots and read-only reports include Features; agents use contract v5. Database v6 adds fields after
making a backup. Upgrades from 0.3?0.5 create a sibling `*.pre-v0.6.0-*.db` backup; use that backup with older
code for rollback. Snapshot v4 imports older snapshots without requiring Features.

Save or close editors before updating, then restart the local app. An open browser reconnects automatically.
