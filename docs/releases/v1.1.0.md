# Sprig 1.1.0

Six game-inspired styles are available in **Preferences > Theme palette**:
**Persona 5, Destiny 2, Alien: Isolation, The Division, Halo, and World of Warcraft**.
Each changes typography, framing and surfaces as well as colors, and supports Light/Dark.
Your current palette stays selected until you choose another. These are original adaptations.

**Sort by** above the board now offers Ticket number, Title, Feature, and Recently updated.
The choice is saved and applies separately within each lane. Feature sorting uses the first
alphabetical assigned Feature name, with unassigned items last. Dragging still changes status;
items settle into the selected sort order in their destination lane.

Project colors now offer twelve choices with swatches, adding Rose, Orange, Lime, Cyan, Indigo,
Pink and Slate. Snapshots using those colors need Sprig 1.1.0 or later to import.

No database migration or JSON shape change. Save/close editors before restarting; your browser
reconnects after the local update. The source package includes all six local style sheets.
