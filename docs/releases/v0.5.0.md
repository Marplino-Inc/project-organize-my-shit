# Organize 0.5.0

This update makes fields and empty lanes clearer and allows project-key renaming.

- Dropdowns and text fields have a slightly darker background. Preferences has a persistent
  **Field border thickness** slider from 1 to 4 px, with immediate feedback.
- Empty lanes no longer stretch to match a populated lane. Their message and Add item button sit
  just below the lane heading, in full and condensed views.
- Edit a project key to update every work item's prefix together, including cancelled items.
  Numbers, UUIDs, relationships, tags and history remain intact. Invalid or occupied keys are rejected.
  Old labels stop resolving; agents should refetch items after renaming because their revisions advance.

Branch prefixes are deferred. Agent contract is v4; database v5 and snapshot v3 are unchanged.
Save or close editors before updating, then restart the local app to refresh an open browser.
