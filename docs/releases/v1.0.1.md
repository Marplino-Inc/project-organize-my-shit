# Sprig 1.0.1

- Removed the decorative tilted stars tile beside the workspace heading.
- Added **GGplot Gray Pastel**: neutral gray/white surfaces with pastel red, blue and green accents.
- Added all 16 **shinythemes** palette adaptations: Cerulean, Cosmo, Cyborg, Darkly, Flatly,
  Journal, Lumen, Paper, Readable, Sandstone, Simplex, Slate, Spacelab, Superhero, United and Yeti.
- Added **Apple HIG**, **Microsoft Fluent** and **IBM Carbon** palette adaptations.

Choose a palette in **Preferences > Theme palette**. There are now 44 families / 88 Light-Dark
variants. Sources remain above the live example. Existing palette choices are retained.

These are color adaptations for Sprig, not full third-party component themes. Typography and layout
stay consistent, and no external CSS, fonts or runtime downloads are added. See
[palette sources](https://github.com/Marplino-Inc/project-organize-my-shit/blob/v1.0.1/docs/theme-sources.md).

No database migration or agent contract change. Save/close editors before restarting; an open browser
reconnects after the local update. The requested version number is 1.0.1, following 0.7.0 directly.
