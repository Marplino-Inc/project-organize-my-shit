# Organize v0.1.0

A colorful local workspace for projects, goals, tasks, and ideas, with an interface for AI agents.

## Download and start

1. Download `organize-0.1.0-windows-source.zip` and extract it into a writable folder.
2. Install [uv](https://docs.astral.sh/uv/getting-started/installation/) if it is not installed.
3. Double-click `Start.cmd`. The app opens at `http://127.0.0.1:8765`.
4. Keep the launcher window open. Press Ctrl+C there to stop the app.

First launch downloads Python/dependencies as needed. After setup, the application uses local assets
and SQLite. There is no cloud account or service to configure. The release includes source and Windows
launchers, not a standalone executable or signed installer. `SHA256SUMS.txt` contains the ZIP checksum.

For the existing Git checkout, pull `main` and double-click `Start.cmd`. To explore sample content,
run `./Start.ps1 -Demo`, which uses a separate database and port 8766.

## Included

- Light / Dark / System themes and colorful project cards.
- Projects, major/minor goals, tasks, subtasks, and ideas; stable project-key IDs and named tags.
- XS–XL or 1–5 effort estimates, card movement, and expandable descriptions.
- Project stages including Still a Dream, Just Designing, and In Progress, separate from task status.
- Repository links, hierarchy outline, relationship map, and dashboard summaries.
- Project snapshot import/export, offline HTML reports, and full SQLite backups.
- A documented JSON CLI so local AI agents can update work with revision checks and activity labels.

Your personal workspace is `%LOCALAPPDATA%/ProjectOrganize/workspace.db`; demo data uses `demo.db`.
Both stay outside the application directory. Before future upgrades, use Preferences → Download
workspace backup. See the README for restoring a backup and using a different workspace file.

## Validation and boundaries

The initial demo's visual direction was accepted by the primary user. Automated data/CLI and Windows
Chromium checks cover the core workflows; the release ZIP is separately checked for first launch and
workspace persistence across a process restart. This is not evidence of long-term daily-use testing.

Large workspaces, other browsers/operating systems, and full screen-reader/accessibility conformance
remain unverified. Map layout and within-column manual ordering are not persisted. Sharing uses
snapshots/reports; there is no concurrent multi-user sync or automatic GitHub issue synchronization.
