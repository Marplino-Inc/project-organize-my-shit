# Organize 0.4.0

This update focuses the interface on projects and tasks.

- Removes Outline, Map and Dashboard; the board and project overview remain.
- Makes the sidebar collapsible, remembers that choice, and fills the available browser width.
- Adds Home and keeps Preferences available in the top toolbar even with the sidebar hidden.
- Moves palette selection exclusively into Preferences as a non-editable dropdown; places source
  attribution above the accepted preview. The toolbar offers Light/Dark only.

- Verifies automatic browser refresh after a local app restart and adds an unsaved-editor reload warning.
  Save or close forms before updating; this is not automatic draft saving or a GitHub updater.

Existing items, tags, links and history are retained; database and agent contract versions are unchanged.
Former System appearance preferences start in Light. See [product scope](../product-scope.md) for the
small core workflow and release boundaries. Use Start.cmd with uv installed; this remains a local
browser application rather than a standalone executable.
