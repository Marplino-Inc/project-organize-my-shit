# Organize 0.3.0

- Sidebar projects display their own description, status, tags, repository, goal count and progress above the work area.
- Card bodies open centered details. Cards no longer have the type/effort footer.
- Condensed view reduces lanes to ticket number and title; the choice is remembered.
- Effort is removed from the app and agent contract. Old values remain in the automatic pre-upgrade backup only.
- 24 palette families, each with light/dark modes, are available through searchable dropdowns. Preferences has a persistent preview.
- Repeated launches reuse a matching running workspace. Port conflicts are diagnosed before data changes, and startup errors are logged.

Stop an older running version before upgrading. First start creates a sibling `*.pre-v0.3.0-*.db`
backup, then migrates the database. To revert, use that backup with the previous version. Agents must
stop writing effort and use the [v3 contract](../agent-interface.md). Snapshot v1/v2 imports remain supported.

Extract the Windows source ZIP and run Start.cmd with uv installed. This remains a local browser app,
not a standalone executable. See [development status](../development-status.md) for validation and limits.
