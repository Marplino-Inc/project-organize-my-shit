# Focused project and task tracking

The main job is to create projects, break them into work items, find the next task, update its status
and retain the result. October 10 feedback explicitly favored condensed cards and the Preferences
example while rejecting extra views as distracting.

Keep one work board and project overviews, full/condensed cards, search/tags, editing, persistence,
backup/snapshot exchange and the established agent interface. Occasional appearance choices belong in
Preferences. A collapsible sidebar and Home keep that workflow usable across browser widths.

Outline, Map and Dashboard are removed. Analytics pipelines, relationship visualizations and new
integrations are outside the current goal. Existing links/hierarchy remain in details and exports;
this UI simplification does not erase project data.

Recommend one coherent outcome per update, normally supported by one to three small changes. Explain
what should wait and why. Ask whether an optional capability helps a real near-term task; do not fill
empty UI space with new features. Explicit larger batches remain authorized. Each commit should have
a reviewable outcome with its relevant checks/docs; several commits can support one update.

For a new product, 0.1.0 should be a small usable end-to-end MVP. For this already-versioned app, preserve
published history and simplify through forward versions. A future 1.0.0 should mean the small core is
reliable in real use: save/reopen, recovery, backup/restore, understandable navigation, installation and
updates. It does not require more views or a feature-count quota.

Acceptance for this update: select a project, open/edit/save a task, and find the result on the board;
collapse the sidebar to use the full browser width; use Home and Preferences without reopening it;
select a palette from a non-editable dropdown while the accepted preview remains visible.

The next review should focus on daily task-tracking friction. Automated checks and accepted visual
examples are useful evidence, but do not establish 1.0 readiness alone.
